# Africa Power Advisory Holdings, Codex Source Package

Use this folder as the source package for the Africa Power Advisory Holdings website project in Codex.

## Add your approved brand assets

Place the official website logo here:

`assets/brand/logo.png`

Place the three real co-founder photographs here:

`assets/team/cofounder-01.jpg`
`assets/team/cofounder-02.jpg`
`assets/team/cofounder-03.jpg`

The filenames are placeholders for file organization only. Keep the real photographs and use the correct name association in the site data once the names and profiles are confirmed.

Do not add a fourth person's photograph unless the company provides an approved image.

## Reference document

The supplied corporate document is included at:

`reference/africa-power-advisory-corporate-documents.pdf`

Treat the corporate document as a source of truth for company facts. Do not invent missing information.

## Codex instruction

Read `CODEX_PROMPT.md` before changing the application. Follow the prompt as the project specification.

## Suggested project asset conventions

- `assets/brand/logo.*` for the official logo.
- `assets/brand/favicon.*` for the favicon generated from the approved logo/brand mark.
- `assets/team/cofounder-01.*` through `cofounder-03.*` for the three supplied photographs.
- `assets/team/fourth-expert-placeholder.svg` for the branded placeholder until the fourth photograph is supplied.

Do not use stock portraits for the expert team.
Do not download competitor photographs.
Do not copy competitor content or source code.
